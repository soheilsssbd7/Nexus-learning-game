# پروتکل پلی‌تست کودکان — تسک ۱۰.۲ (افزودۀ ایجنت؛ سند ۰۴ §۱۰.۲ آن را می‌خواهد)

**برای چه کسی:** ۳ تا ۵ کودک ۹ تا ۱۲ سال، فارسی‌زبان، روی همان دستگاهی که خودشان با آن بازی می‌کنند
(تبلت یا گوشی؛ Android 8+ یعنی API 26 به بالا ✓ `minSdk` فاز ۱۰). والد **کنار کودک می‌نشیند ولی
هیچ کاری نمی‌کند** — نه اشاره، نه «اینجا بزن» ✓✗ این تنها قاعدۀ اخلاقیِ جلسه نیست، تنها قاعدۀ
**مفید** بودنش هم هست: به‌محض اینکه بزرگ‌تر کمک کند، داده‌های ۵ کارِ زیر بی‌معنا می‌شوند ✓

**چه چیزی را نمی‌سنجیم:** ریاضی. ۴۵ سطح و «هیچ زیرمجموعۀ نابرده‌ای» را `tools/validate_levels.py`
و باتِ GUT (`test_all_content_playable.gd`) **قبلاً**-machine ثابت کرده‌اند ✓§۷. پس وقتِ کودک
صرفِ چیزی می‌شود که هیچ ابزاری نمی‌تواند ببیند: **منظورِ پیام، حوصله، و انگشت**.

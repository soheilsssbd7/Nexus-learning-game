## چه چیزی جمع می‌شود
۱. **شناسۀ تصادفی بازیکن** ✓ — رشته‌ای به شکل `p_193f2a7e` که روی دستگاه ساخته می‌شود ✓
   هیچ‌گونه نگاشت به نام، شماره، ایمیل، یا دستگاه فیزیکی ندارد ✓ (قاعدۀ §۲ سند فنی ✓)
۲. **دادهٔ عملکرد آموزشی** ✓ — زمانِ حل هر سطح، تعدادِ تلاش‌ها، تعدادِ راهنماهای دیده‌شده،
   و رتبۀ یادگیری هر مهارت (یک عدد از ۶۰۰ تا ۲۶۰۰) ✓ این‌ها برای همین ساخته شده‌اند که
   دشواری را تنظیم کنند و در «داشبورد والدین» به شما نشان داده شوند ✓
۳. **شش نوع رویدادِ یادگیری، نه بیشتر** ✓ — دقیقاً: `session_start` · `session_end` ·
   `level_started` · `level_completed` · `hint_shown` · `error_occurred` ✓
   (هر رویداد = نوع + شناسۀ تصادفی + زمان + چند عدد ✓✗ **هیچ متنی** از کودک فرستاده نمی‌شود ✓)
۴. **توکنِ دستگاه** ✓ — یک رشتهٔ امضاشده برای این‌که سرور بداند این درخواست مالِ کدام
   شناسۀ تصادفی است ✓ بدون جدول کاربر، بدون ایمیل، بدون رمز عبور ✓ (ADR-063)
۵. **هرچه روی دستگاه می‌ماند** ✓ — نامِ نمایشیِ پروفایل (اگر خودتان بنویسید)، تنظیمات صدا،
   و کلیدِ پیشرفت بازی ✓ این‌ها **به سرور ما فرستاده نمی‌شوند** ✗✓ مگر مورد ۲ و ۳ (و
   نامِ پروفایل هرگز ✓).

۲. **پاک کردن همه‌چیز** ✓ — «حذف اپ» یا «پاک کردن داده‌های برنامه» روی اندروید، هر دو سطرِ

   بفرستید: « شناسۀ `p_…` را حذف کن» ✓ ما بدونِ دانستنِ هیچ چیزِ دیگری آن را حذف می‌کنیم ✓

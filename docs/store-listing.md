**بلند:**
```
NEXUS یک بازی آموزشی جبر است برای 9-15 سال. وعده‌اش یک جمله است: ترازو را متعادل کن و ریاضی را بفهم.

• ۴۵ سطح در ۵ منطقه + یک شهر مرکزی؛ از ترازوی ساده تا معادله با مجهول روی دو کفه.
```

## ۲) English
**Title (≤ 30 ✓):** `NEXUS: Algebra Balance`
**Short (≤ 80 ✓):** `Feel the balance, understand the algebra. Offline, no ads, no in-app purchases.`
**Long:**
```
NEXUS is an algebra game for ages 9-15. Its promise in one line: balance the scale and you understand the maths.

• 45 levels across 5 regions plus a hub city, from a simple balance to equations with the unknown on both pans.
• An adaptive engine tunes difficulty from a learning curve: solve time, attempts and hints used — never a "score".
• Aria is a companion, not a teacher: it asks and points, and never says the answer.
• No punishment: no aggressive red, no pressure timer, no "fail". A wrong attempt is information.
• Accessibility: colour-blind mode (pattern + colour), text zoom, haptics off, high text contrast.
• Parent dashboard behind a parent gate: learning curves, anxiety signals, a JSON export you can send a teacher.
• Fully offline; cloud sync is an explicit switch and off means no request is built at all.
• One-time purchase: no ads, no in-app purchases, no subscription, no third-party SDK.
• Requires Android 7.0 (API 24) or newer; built for cheap, low-memory phones.

Privacy policy and parent guide: https://soheilsssbd7.github.io/Nexus-learning-game/
```

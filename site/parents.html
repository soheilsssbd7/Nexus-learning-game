۱) پنل والدین کجاست و چه چیزی نشان می‌دهد

ورودیِ پنل پشت قفل والدین است (یک پرسشِ سادهٔ بزرگسال‌محور ✓ نه ثبت‌نام، نه ایمیل ✗) تا کودک خودش واردش نشود ✓ پنل روی دستگاه کار می‌کند و چیزی از شما نمی‌خواهد ✗

  • خروجیِ قابل‌کپی ✓ پنل یک JSON کوچک می‌سازد که می‌توانید برای معلم/مدرسه بفرستید ✓ هیچ سرویسی این خروجی را نمی‌گیرد ✗✓ کپی می‌کنید و خودتان هر جا می‌خواهید می‌گذارید ✓

۲) همگام‌سازی ابری: کلیدِ واقعی، نه نمایشی

تنظیمات → حریم خصوصی → همگام‌سازی ابری ✓ وقتی خاموش است، بازی هیچ درخواست شبکه‌ای برای ارسال داده نمی‌سازد ✗✓ (کدش در مخزن با تستِ خودکار سنجیده شده: «ارسال کن ولی دور بریزیم» نداریم ✓) آنچه در حالت روشن می‌رود = فقط شناسۀ تصادفی + دادهٔ عملکرد آموزشی ✓ بدون نام، بدون متن، بدون صدای کودک ✓

# راهنمای والدین

این صفحه تنها جایی است که **ابزارهای کنترل** را توضیح می‌دهد ✓ سیاستِ جمع‌آوری داده را
[این‌جا](privacy.html) خوانده‌اید ✗✓ اینجا «چطور» را می‌خوانید ✓

## ۱) پنل والدین کجاست و چه چیزی نشان می‌دهد
ورودیِ پنل پشت **قفل والدین** است (یک پرسشِ سادهٔ بزرگسال‌محور ✓ نه ثبت‌نام، نه ایمیل ✗) تا کودک
خودش واردش نشود ✓ پنل **روی دستگاه** کار می‌کند و چیزی از شما نمی‌خواهد ✗

- **منحنی یادگیری به تفکیک مهارت** ✓ — نه «نمره»، بلکه این‌که هر مهارت (تراز ساده، جمع روی دو کفه،
  مجهول، کسرهای هم‌مخرج، …) در کدام مرحله از یادگیری است: فراموشی / آشنایی / کاربری / تسلط ✓
- **نشانه‌های اضطراب** ⚠ — تعدادِ «تلاش‌های پشت‌سرهمِ بدون پیشرفت» و «راهنماهای پیاپی» ✓ این‌ها را
  نشانهٔ *اضطراب* می‌دانیم، نه تنبلی ✓ و پیامِ بازی هم به همان سمت تنظیم می‌شود ✓
- **زمانِ نشست و تعدادِ سطح‌های تمام‌شده** ✓ (نه امتیاز ✓)
- **خروجیِ قابل‌کپی** ✓ پنل یک JSON کوچک می‌سازد که می‌توانید برای معلم/مدرسه بفرستید ✓
  هیچ سرویسی این خروجی را نمی‌گیرد ✗✓ کپی می‌کنید و خودتان هر جا می‌خواهید می‌گذارید ✓

## ۲) همگام‌سازی ابری: کلیدِ واقعی، نه نمایشی
`تنظیمات → حریم خصوصی → همگام‌سازی ابری` ✓ وقتی **خاموش** است، بازی هیچ درخواست شبکه‌ای برای
ارسال داده نمی‌سازد ✗✓ (کدش در مخزن با تستِ خودکار سنجیده شده: «ارسال کن ولی دور بریزیم» نداریم ✓)
آنچه در حالت روشن می‌رود = فقط شناسۀ تصادفی + دادهٔ عملکرد آموزشی ✓ بدون نام، بدون متن، بدون صدای کودک ✓

## ۳) حذف داده
۱. روی دستگاه: «پاک کردن داده‌های برنامه» (Android → Apps → NEXUS → Storage ✓) یا حذفِ اپ ✓
۲. روی سرور ما: یک پیام به [نشانیِ پشتیبانی](support.html) بفرستید و فقط بگویید «این شناسۀ `p_…` را حذف کن» ✓
   ما بدون دانستن هیچ چیز دیگری حذفش می‌کنیم ✓✗ (پاسخِ انسانی تا راه‌اندازیِ فرم، دستی است ✓§۱۲.۴ ⚠)

## ۴) صفحهٔ کودکِ من چه می‌بیند
- **هیچ تبلیغ، هیچ خرید، هیچ لینکِ بیرونی** ✗✓ تنها لینکِ بیرونیِ بازی (بازخورد/پشتیبانی) **پشت قفل والدین** است ✓
- **بدون قرمزِ تنبیهی**: خطا با رنگِ مرجانیِ گرم و حرکت نشان داده می‌شود، نه با قرمز ✗✓ (کاهش اضطراب ریاضی ✓)
- **بدون چت، بدون نام کاربری، بدون محتوای دیگران** ✓ کودک با هیچ کودک دیگری در ارتباط نیست ✓
- صفحه روشن می‌ماند تا وسطِ تمرین نورِ صفحه نپرد ✓ (و می‌توانید در تنظیمات غیرفعالش کنید ✓)

## ۵) چند دقیقه‌ی بازی در روز
بازی نشست‌محور طراحی شده و «شکست» ندارد ✗ ولی هیچ «قفل والدینِ زمان‌سنج» هم ندارد ⚠ — یعنی
مدیریتِ زمان با خودِ شماست ✓ (عمداً افزونۀ ردیابیِ زمان ننوشتیم ✗✓ چون یعنی جمع‌آوری داده ✓)

# پشتیبانی

## چطور با ما صحبت کنید
- **ایمیل:** ⚠ `support@<host>` — پیش از انتشارِ عمومی جایگزین می‌شود ✓ تا آن زمانِ نوشتن،
  آدرسِ رسمی در این صفحه قرار می‌گیرد (تسک ۱۲.۴ ✓) و گیتِ سایت، نبودِ `<host>` را در نسخۀ
  منتشرشده قرمز می‌کند ✓✗ پس «صفحه‌ای که قول می‌دهد و آدرس ندارد» روی Pages نمی‌ماند ✓
- **گزارشِ اشکال روی اندروید:** نسخهٔ بازی (Settings → About ✓) + مدلِ گوشی + نسخهٔ اندروید + یک
  جمله دربارهٔ کاری که کردید ✓ این چهار چیز کافی است؛ **هیچ‌وقت** نام یا شناسۀ بازی کودک را
  در گزارشِ عمومی (مثلاً GitHub issue) ننویسید ✗✓ شناسۀ `p_…` هم دادهٔ حساسی نیست ولی لازم هم نیست ✓

## درخواستِ حذف داده
یک پیام کافی است با همین متن: «حذف داده — `p_…`» ✓ ما هیچ چیزِ دیگری نمی‌پرسیم ✗✓ (چون پرسیدنِ نام/ایمیل
برای *حذف* داده، خودش جمع‌آوری داده است ✓) حذف در همان روزِ کاری انجام می‌شود و عددِ ردیف‌های پاک‌شده
به شما اعلام می‌شود ✓

## اگر بازی روی گوشی‌تان اجرا نشد
حداقلِ لازم: **اندروید ۷.۰ (API 24)** به بالا ✓ (minSdk ✓§۰ سند فنی) و ARM64 ✓ روی اندروید ۱۵/۱۶
اپ از الزاماتِ لبه‌به‌لبه و «بازگشتِ پیش‌بینی‌شده» پیروی می‌کند (target API 36 ✓) ✓ اگر وسطِ سطحی
بازی ببندد، پیشرفتِ همان سطح بازمی‌گردد ولی سطح‌های تمام‌شده می‌مانند ✓ (سیاستِ ذخیره: هر سطح تمام‌شده
بلافاصله ✓ نه فقط آخرِ نشست ✓)

## چیزهایی که ما **نمی‌توانیم** انجام دهیم ⚠ (شفافیت)
- بازی را از راه دور روی دستگاه شما درست نمی‌کنیم ✗ (هیچ دسترسیِ راه دور نداریم ✓ و عمداً نساختیمش)
- گزارشِ فنیِ خرابی (crash log) را **خودکار** دریافت نمی‌کنیم ✗✓ هیچ crash-reporter شخص ثالثی نداریم ✓
  پس اگر چیزی شکست، یک جملهٔ شما تنها داده‌ای است که ما داریم ✓ (و همین، سیاستِ حریم خصوصی‌مان را راست نگه می‌دارد ✓)
